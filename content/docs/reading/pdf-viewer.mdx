Open a `.pdf` and it opens in a Suzuri tab, not in Preview or a browser. That
matters because the PDF is the other half of the work: the paper you're citing,
the draft you just compiled, the figure you're checking.

- **Continuous scroll** through the whole document, not a page at a time
- **Real text selection** — glyph-accurate, so copied text is the document's
  text, not OCR
- **Zoom**, fit-to-width, and actual size
- **Links work**: web and email links open in your browser, and citations,
  footnotes, and cross-references jump to their place in the document. Links
  to local files or apps are not followed
- **Reloads in place** when the bytes change on disk, keeping your scroll
  position — which is what makes [typeset preview](/typesetting) feel live

It works on remote projects too: a PDF rewritten on an SSH host reloads in the
local pane.

## Keybindings

### Moving through the document

The keys follow Acrobat and Preview.

| Action | macOS | Windows and Linux |
| --- | --- | --- |
| Next / previous page | <kbd>→</kbd> / <kbd>←</kbd>, <kbd>Option</kbd>+<kbd>↓</kbd> / <kbd>↑</kbd>, <kbd>Cmd</kbd>+<kbd>Page Down</kbd> / <kbd>Page Up</kbd> | <kbd>→</kbd> / <kbd>←</kbd> |
| First / last page | <kbd>Home</kbd> / <kbd>End</kbd>, <kbd>Cmd</kbd>+<kbd>↑</kbd> / <kbd>↓</kbd>, <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>↑</kbd> / <kbd>↓</kbd> | <kbd>Home</kbd> / <kbd>End</kbd>, <kbd>Ctrl</kbd>+<kbd>Home</kbd> / <kbd>End</kbd>, <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>↑</kbd> / <kbd>↓</kbd> |
| Scroll a little | <kbd>↓</kbd> / <kbd>↑</kbd>, <kbd>J</kbd> / <kbd>K</kbd> | <kbd>↓</kbd> / <kbd>↑</kbd>, <kbd>J</kbd> / <kbd>K</kbd> |
| Scroll a screen | <kbd>Page Down</kbd> / <kbd>Page Up</kbd>, <kbd>Space</kbd> / <kbd>Shift</kbd>+<kbd>Space</kbd>, <kbd>Return</kbd> / <kbd>Shift</kbd>+<kbd>Return</kbd> | <kbd>Page Down</kbd> / <kbd>Page Up</kbd>, <kbd>Space</kbd> / <kbd>Shift</kbd>+<kbd>Space</kbd>, <kbd>Enter</kbd> / <kbd>Shift</kbd>+<kbd>Enter</kbd> |
| Go to page | <kbd>Cmd</kbd>+<kbd>Option</kbd>+<kbd>G</kbd> or <kbd>Ctrl</kbd>+<kbd>G</kbd> | <kbd>Ctrl</kbd>+<kbd>G</kbd> |

**Previous page** first goes to the top of the page you are partway down,
then to the page before it. **Scroll a screen** keeps the last line of the
old screen in view, so you don't lose your place.

**Go to page** puts the cursor in the page number at the top left: type a
number and press <kbd>Enter</kbd>, or <kbd>Esc</kbd> to leave it. While you
type there, these keys go to the box, not the document.

### Zoom and copy

| Action | macOS |
| --- | --- |
| Zoom in | <kbd>Cmd</kbd>+<kbd>=</kbd> |
| Zoom out | <kbd>Cmd</kbd>+<kbd>-</kbd> |
| Reset zoom | <kbd>Cmd</kbd>+<kbd>0</kbd> |
| Actual size (100%) | <kbd>Cmd</kbd>+<kbd>1</kbd> |
| Fit to view width | <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>0</kbd> |
| Copy all document text | <kbd>Cmd</kbd>+<kbd>C</kbd> |

On Windows and Linux, substitute <kbd>Ctrl</kbd>. Every key here is an action
in the command palette (`pdf_viewer: next page`, `pdf_viewer: fit to view`,
and so on), so you can [rebind it](/reference/keybindings).

<Callout title="Copy all document text">
<kbd>Cmd</kbd>+<kbd>C</kbd> with no selection copies the *entire* document's
text — handy for pasting a paper into an agent thread.
</Callout>

## Getting to a PDF

- Click a `.pdf` in the project panel
- Follow a `[](...)` link to an [attached PDF](/writing/attachments)
- Put the cursor on a cite key and press
  <kbd>Cmd</kbd>+<kbd>Alt</kbd>+<kbd>O</kbd> — see
  [Citations](/writing/citations)
- Preview a `.typ` or `.tex` file — see [Typesetting](/typesetting)
